# Metabolic Model Builder

An interactive web application for reconstructing genome-scale metabolic models using **CarveMe**.

## 🌟 Features

- **Interactive Interface**: User-friendly Streamlit web app
- **Model Reconstruction**: Build metabolic models from genome sequences
- **CarveMe Integration**: Automatic gene annotation and pathway reconstruction
- **Multiple Organisms**: Support for various bacterial species
- **SBML Export**: Export models in SBML format for analysis
- **FBA Analysis**: Built-in constraint-based flux analysis
- **Visualization**: Interactive metabolic network visualization

## 📋 Requirements

- Python 3.8+
- CarveMe
- COBRApy
- Streamlit
- Pandas
- Plotly

## 🚀 Installation

1. Clone the repository:
```bash
git clone https://github.com/realcuiyonghao94/metabolic-model-builder.git
cd metabolic-model-builder
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Install CarveMe database (required for full genome reconstruction):
```bash
carveme download -d bigg
```

## 🎯 Usage

Start the application:
```bash
streamlit run metabolic_model_app.py
```

Then:
1. **Select Organism**: Choose from predefined organisms or enter custom
2. **Upload Genome**: FASTA file of your organism's genome
3. **Configure Model**: Set organism name, ID, and other parameters
4. **Build Model**: Generate the metabolic model
5. **Download**: Export as SBML XML file

## 📊 Supported Organisms

- **E. coli** (Escherichia coli K-12 MG1655)
- **C. glutamicum** (Corynebacterium glutamicum ATCC 13032)
- **Custom**: Upload your own genome FASTA file

## 🔬 Model Output

Models are generated in **SBML format** containing:
- Reactions and metabolites
- Gene-protein-reaction associations
- Compartments (cytoplasm, extracellular, etc.)
- Reaction bounds and objective functions

### Use with COBRApy

```python
from cobra.io import read_sbml_model

model = read_sbml_model('model.xml')

# Run FBA
solution = model.optimize()
print(f"Growth rate: {solution.objective_value}")

# Analyze reactions
for reaction in model.reactions:
    print(f"{reaction.id}: {reaction.bounds}")
```
